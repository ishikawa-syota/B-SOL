# B&SOL Career LP コーディングデータ

## ファイル構成

- `index.html` — LP本体

CSS、JavaScript、主要画像は `index.html` 内にまとめています。ビルド作業は不要です。

## 確認方法

`index.html` をブラウザで開いてください。

## 公開方法

レンタルサーバー、Netlify、Cloudflare Pagesなどの公開ディレクトリ直下へ、`index.html` をアップロードしてください。
